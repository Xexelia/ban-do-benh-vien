# Bản đồ & chỉ dẫn bệnh viện

Website tĩnh giúp người dùng tìm phòng, chuyên khoa và xem lộ trình trên sơ đồ 3 tầng.

## Chạy website

Mở `index.html` trực tiếp hoặc chạy máy chủ tĩnh:

```bash
python3 -m http.server 8080
```

Sau đó truy cập `http://localhost:8080`.

Website được thiết kế cho GitHub Pages và không cần cài thêm thư viện.
